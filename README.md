# Math Test Dashboard

一个从日常备考里慢慢做出来的数学错题工作台。

记下错题只是开始，更难的是知道什么时候该回头做、哪些题还没真正掌握，以及每天到底该花多少时间复习。这个项目把这些事情放到同一个页面里，让错题不只是被收藏，而是能持续回顾。

## 它能做什么

### 看清学习情况

总览展示各题册的记录数量、ABC 错题分布和单元初始正确率。初始正确率只看第一次做题的表现，不把后来的复盘成绩混进去，方便回看每个单元最初学得怎么样。

错题可以按题册、单元、等级查看；对于按页码组织的题册，还能按板块、题型和页码筛选。

*项目中的 660、880、800 是不同数学练习册的简称。*

### 把错题重新做一遍

复习分成今日队列和遗留队列。每天按计划回顾，到时间了还没做完，就把剩余题移入遗留，之后有空再清理，不必强迫自己当天全部完成。

- 用 A / B / C 区分“会做但算错”“有思路但卡住”和“无从下手”。
- 根据复盘结果安排下一次回顾，做对后拉长间隔，仍错则回到短间隔。
- 按页码集中题目，减少来回翻练习册；遗留队列也支持页码降序。
- 完成常规复习的题进入毕业题库，保留低频维护，而不是从此消失。

### 留下复盘的过程

每次复盘可以写 comment，记下这次卡在哪里、换了什么思路。点错了也可以修改最近两天的记录，跨过零点不用担心刚才的操作找不到。

日期分组、累计复盘数和完成率热力图，让每天的投入有迹可循。

### 分享进度，不打断自己的使用

除了日常操作的工作台，还做了独立的只读展示副本，可以展示复盘进度和记录，支持定时更新与手动刷新，不提供修改错题的操作。

## 做这个项目时在意的事

- **贴着真实使用改。** 从错题分级、翻页顺序，到跨日记录和遗留队列，功能主要来自每天使用时遇到的不方便。
- **复习规则能看懂。** 使用可解释的机械间隔与持久化计划，不把复习安排交给一个说不清原因的“智能算法”。
- **尽量少打扰。** 题号、comment 和反馈按钮放在相近的视线范围内，今日与遗留队列并排展示，也能折叠收起。
- **适合长时间看。** 支持暖米色、玻璃质感主题和深色模式，在保留层次的同时减少大面积亮白。

## 实现

Python / FastAPI 提供服务，原生 HTML、CSS 和 JavaScript 构建界面，Pixi 管理开发环境。题目、复盘历史和计划使用 JSON 保存，应用代码与个人学习记录分开管理，并通过 Git 同步记录。

本着够用就行的想法搭起来的，所以各方面都挺草台班子的，特别是前端和数据存储。

> [!NOTE]
> 自 v0.3.0 起，OCR 批次功能已弃用并从项目中移除。当前版本聚焦于错题记录可视化、机械式回滚复习与复盘历史管理。
